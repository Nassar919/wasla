# وصلة، خدماتك أقرب

تطبيق ويب تقدمي لدليل خدمات كفر شكر والقرى التابعة. نسخة تجريبية بإعلانات وصور توضيحية، وليست إعلانات أنشطة حقيقية.

## إدارة الإعلانات

عدّل ورقة Listings في ملف Google Sheets المرتبط. كل صف إعلان واحد. يجب أن يظل الصف الأول بأسماء الأعمدة التالية:

`id | name | category | description | phone | location | image | featured | active | sample`

- id: رمز فريد لا يتغير، مثل ad-001.
- name: اسم النشاط.
- category: health أو food أو repair أو education أو rides أو mobile أو grocery أو fashion.
- description: وصف مختصر.
- phone: رقم الاتصال الحقيقي بعد إذن صاحبه. نسّق العمود كنص عادي للحفاظ على الصفر. يمكن استخدام +20.
- location: عنوان النشاط أو نطاق الخدمة.
- image: رابط صورة HTTPS مسموح بنشرها، أو إحدى الصور التوضيحية المدمجة doctor أو pizza أو grocery أو ride أو fashion أو repair. لا تستخدم صورة مولدة على أنها صورة النشاط الحقيقي.
- featured: TRUE لعرض الإعلان ضمن المميزة.
- active: TRUE للنشر، FALSE للإخفاء.
- sample: TRUE للنماذج التجريبية، FALSE للإعلان الحقيقي. النموذج لا يعرض رقم اتصال فعالًا.

أضف إعلانًا حقيقيًا بإذن صاحبه مع active=TRUE وsample=FALSE. أخفِ النماذج بجعل active=FALSE. التحديث يظهر عند فتح التطبيق أو الضغط على تحديث. المميزة تعرض أول إعلانين بحسب ترتيب الشيت، والأحدث أول ثلاثة إعلانات غير مميزة بحسب ترتيب الصفوف، فضع الأحدث في الأعلى. عرض الكل يظهر باقي الإعلانات.

الملف قابل للقراءة لأي شخص لديه الرابط. كل الأعمدة والصفوف، حتى active=FALSE، يمكن قراءتها من المصدر. لا تحفظ بيانات خاصة أو طلبات غير منشورة في هذا الملف. بيانات التواصل تستعمل بعد إذن أصحابها فقط.

## الخصائص

بحث عربي، تصفية بالأقسام، مفضلة محلية على الجهاز، اتصال مباشر للأرقام الحقيقية، طلب إضافة إعلان عبر واتساب، تعليمات تثبيت، عمل أساسي دون اتصال بعد أول زيارة ناجحة. لا توجد حسابات مستخدمين أو إشعارات دفع أو مدفوعات أو لوحة مراجعة طلبات داخل التطبيق.

زر ملفي هو معلومات وخصوصية وتثبيت، وليس حساب مستخدم. زر الجرس يعرض حالة محلية ولا يرسل إشعارات دفع. عند انقطاع تحديث الشيت تظهر آخر نسخة محفوظة مع حالة الاتصال.

الإعدادات في CONFIG داخل index.html. الصور المدمجة توضيحية مولدة. عدّل رقم التواصل والرابط باستخدام إعدادات التطبيق عند الحاجة.
